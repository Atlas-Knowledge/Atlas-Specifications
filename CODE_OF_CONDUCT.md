# Code of Conduct

Atlas welcomes respectful, constructive collaboration.

Participants are expected to:

- Be respectful.
- Be professional.
- Focus on technical discussions.
- Accept constructive feedback.
- Respect differing opinions.

Unacceptable behavior includes:

- Harassment
- Personal attacks
- Discrimination
- Abusive language
- Disruptive behavior

Project maintainers may moderate discussions to preserve a productive environment.
