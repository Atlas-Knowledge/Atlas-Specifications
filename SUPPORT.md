# Support

## Documentation

Begin with:

- README.md
- SPECIFICATIONS.md
- ASF-0001

## Questions

Questions regarding specifications should reference the relevant specification identifier.

Example:

- AKS-0001
- AES-0001
- AVS-0001

## Bug Reports

Implementation bugs belong in implementation repositories.

Specification issues belong in Atlas-Specifications.

## Feature Requests

Major changes SHOULD begin with an RFC before implementation.
