# Security Policy

## Reporting Security Issues

If you discover a security issue affecting Atlas Specifications, please report it privately to the project maintainers.

Please include:

- Description
- Impact
- Steps to reproduce
- Suggested mitigation (if available)

Do not publicly disclose security vulnerabilities before they have been reviewed.

---

## Scope

This repository primarily contains normative specifications.

Security issues generally relate to:

- Specification integrity
- Traceability
- Provenance
- Compatibility
- Conformance

---

## Responsible Disclosure

Atlas follows responsible disclosure principles.

Security reports will be acknowledged, reviewed, and resolved as appropriate.
