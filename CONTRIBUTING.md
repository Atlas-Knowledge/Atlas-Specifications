# Contributing

Thank you for contributing to Atlas Specifications.

## Before Contributing

Please read:

- GOVERNANCE.md
- SPECIFICATION_PROCESS.md
- ASF-0001

## Contribution Process

1. Open an issue.
2. Discuss the proposed change.
3. Submit an RFC if required.
4. Create a Pull Request.
5. Complete technical review.

## Requirements

Contributions SHOULD:

- Preserve backward compatibility.
- Follow ASF-0001.
- Include rationale.
- Update references where necessary.

Editorial changes may not require an RFC.

Normative changes generally require review.
